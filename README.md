Digital Attendance Register
A web-based digital attendance management system designed to streamline, automate, and modernize the tracking of attendance. This platform replaces traditional paper-based registers, making attendance logging fast, accurate, and easily accessible for administrators and educators.

Features:
User Roles & Access Control
Admin Dashboard: Full administrative power to create and manage teacher accounts, register students, and modify core system parameters.

Teacher/Instructor Dashboard: Complete autonomy over class management, logging student attendance, and updating records.

Class & Course Management
Dynamic Schedules: Teachers can create classes, add custom descriptions, set the number of allowed absences before a student is dropped, and input specific meeting days/times.

Automatic Session Detection: The application intelligently determines and displays the active class based on the current system time and day.

Attendance Tracking:
One-Click Logging: Easily mark students as Present, Absent, or Excused via an intuitive interface.

Smart Verification Filters: Filter lists to isolate absent or excused students for verification before committing logs to the database.

Automated Warning System: Increments student absence counts automatically. Triggers an alert or flags the student to be dropped if they meet the pre-configured absence threshold.

Absence Reset/Card Claiming Workflow: Seamless flow to track students returning to class, resetting their absence counters upon validation.

Tech Stack
Backend: PHP / Laravel Framework

Frontend: HTML5, CSS3, JavaScript (enhanced with responsive UI frameworks like Bootstrap)

Database: MySQL / PostgreSQL
